Athena - Privacy Policy

Effective date: November 24, 2026 Last updated: November 24, 2026

Athena ("the App") is a personal, self-hosted productivity system built and operated by Eddie Xiao ("I", "me"). It is used only by its developer to manage his own calendar, tasks, email, and notes. It is not offered as a commercial service and is not available to the public for sign-up.

This policy explains how Athena accesses, uses, stores, and shares data received from Google APIs and other sources.

1. Who can use Athena

Athena is used only by me with Google accounts I own. If any other person authorizes the App, this policy applies to their data in the same way.

2. Google user data Athena accesses

Athena requests only the scopes it needs:

Google API Scope What Athena does with it
Gmail API https://www.googleapis.com/auth/gmail.readonly Reads messages to summarize and categorize them, and to extract attachments (receipts, bills, tickets) into my personal document archive. Athena does not send, delete, or modify email.
Google Calendar API https://www.googleapis.com/auth/calendar.events Reads events on a designated calendar for processing, and creates or updates events I approve or have configured to be added automatically (e.g., flights, deadlines).
Google Tasks API https://www.googleapis.com/auth/tasks Reads tasks from a designated inbox list, and creates, updates, and completes tasks.
Google Sign-In openid, email, profile Identifies which of my Google accounts is connected.

3. How Google user data is used

Google user data is used only to provide Athena's user-facing features for the account owner:

  • Summarizing and categorizing my email.
  • Creating, updating, and organizing my calendar events and tasks.
  • Filing email attachments (receipts, bills, tickets, letters) into my personal document archive.
  • Linking items to my personal notes and showing them in my private dashboard.

Google user data is not used for advertising, is not sold, and is not used to build user profiles for any other purpose.

4. Automated processing and AI models

Athena uses language models to categorize, tag, and extract fields from content (e.g., a due date from a bill or a flight time from a ticket). It does not use them to generate content on my behalf.

  • Gmail data is processed only by models running on infrastructure I control or self-host (my own computer, or a self-hosted model server I have access to). Gmail data is not sent to third-party commercial AI providers.
  • Google user data is never used to develop, improve, or train generalized or non-personalized AI or machine-learning models.

5. How data is stored

  • Data is stored on private servers I control: a personal computer and a virtual machine, both reachable only over a private network (Tailscale). No public network ports are exposed.
  • Stored data may include: email metadata and summaries, extracted attachments, calendar and task identifiers, and OAuth refresh tokens.
  • OAuth tokens and secrets are stored encrypted at rest.
  • Backups are encrypted before leaving my infrastructure.

6. How data is shared

Athena does not share, sell, or transfer Google user data to third parties, except:

  • Infrastructure providers that host the servers and encrypted backups, acting only on my instructions.
  • When required by law, or to protect against security threats or abuse.

No humans other than me read Google user data. The only exceptions are security purposes, legal compliance, or with explicit consent.

7. Limited Use disclosure

Athena's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Data retention and deletion

  • Email summaries and metadata are kept for as long as they are useful to me and can be deleted at any time.
  • Documents filed from email attachments are kept in my personal archive until I delete them.
  • Revoking access: you can revoke Athena's access at any time at Google Account → Security → Third-party apps. When access is revoked, Athena stops accessing the account and deletes the stored OAuth tokens.
  • Deletion requests: to request deletion of any data associated with your account, contact me (Section 10). Requests are completed within 30 days.

9. Security

Athena is protected by private-network-only access, encrypted secrets, the least-privilege scopes listed above, and an audit log of automated actions. No system is perfectly secure, but I take reasonable measures to protect stored data.

10. Contact

Eddie Xiao Email: privacy@eddiexiao.com Website: https://eddiexiao.com/athena

11. Changes to this policy

If Athena starts accessing new types of Google user data or using data in new ways, this policy will be updated before that change takes effect, and the "Last updated" date will change.
